BRAND PERFORMANCE DIAGNOSTIC — BUSINESS-CONTEXT TEST

WHAT THIS VERSION DOES
- Adds Website to the client details screen.
- Uses the exact 20 diagnostic answers and calculated scores.
- Sends client name + website + diagnostic data to a Netlify Function.
- The function asks OpenAI to review the client's own website and write a bespoke report.
- The API key remains server-side. It is never placed in the browser code.
- This is still a report PREVIEW. It does not send the email yet.

NETLIFY SETUP
1. Deploy this project through Netlify with Functions enabled.
   For a project containing a serverless function, Git deployment or Netlify CLI is the safest route.
2. In Netlify, add an environment variable:
   OPENAI_API_KEY = your OpenAI API key
   Scope it to Functions.
3. Optional:
   OPENAI_MODEL = gpt-5.1
4. Redeploy after adding/changing environment variables.
5. Complete the diagnostic and select "View Test Email".

IMPORTANT
A simple static drag-and-drop publish may not correctly deploy/bundle the serverless function.
If the report screen says the live analysis is not connected, check:
- the function deployed
- OPENAI_API_KEY exists with Functions scope
- the site has been redeployed after adding the variable
